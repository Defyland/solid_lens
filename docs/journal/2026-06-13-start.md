# 2026-06-13 - Project Start

## Objective

Create `solid_lens`, a Ruby gem for causal diagnostics of Solid Queue in production Rails apps.

## Premise Check

The risk is not "Redis or no Redis." With Solid Queue, the operating risk moves to database capacity and query behavior: connection pool sizing, lock support, queue discovery queries, dispatcher lag, stale process claims, and table bloat.

The MVP must not become a generic monitoring dashboard. It should produce actionable findings with evidence and recommendations.

## Source Facts Verified

- Solid Queue is described by its README as a database-backed Active Job backend.
- The README states Solid Queue can use MySQL, PostgreSQL, or SQLite and leverages `FOR UPDATE SKIP LOCKED` when available.
- The README states Solid Queue is configured by default in new Rails 8 applications.
- The README states high-throughput use is designed around MySQL 8+, MariaDB 10.6+, or PostgreSQL 9.5+ because these support `FOR UPDATE SKIP LOCKED`.
- The current RubyGems listing showed `solid_queue` 1.4.0 published on 2026-03-20.
- RubyGems listing showed Rails 8.1.3 published on 2026-03-24 and requiring Ruby >= 3.2.0.

## Initial Technical Decisions

- Runtime target: Ruby >= 3.2. Local project version pinned to Ruby 3.4.9 because that is installed in this workspace.
- Dependency target: `solid_queue >= 1.4, < 2.0`, `railties/activerecord/activesupport >= 7.1, < 9.0`.
- No Rails engine UI. Use a Railtie only to load `solid_lens:*` Rake tasks.
- Keep diagnostics testable outside Rails by isolating ActiveRecord access in collectors.
- Report formats: Markdown by default, JSON for CI.

## Implemented MVP Surface

- `bin/rails solid_lens:doctor`
- `bin/rails solid_lens:profile DURATION=60`
- `bin/rails solid_lens:explain`
- `bundle exec solid_lens doctor|profile|explain`

## Known Risk

Rails/Rake handling of long options after a task name is version-sensitive. The task implementation accepts `--duration=60` if it reaches `ARGV`, but documents `DURATION=60` as the stable Rake form.
